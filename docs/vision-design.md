# 视觉模型设计草案

## 适用假设

初期假设单件物料停稳拍摄、固定背景与光源、电脑作为上位机。这些是假设，须经需求确认；示例类别不代表最终物料清单。

## 路线一：传统视觉基线

采集 → ROI 裁剪 → 图像质量检查 → 前景分割 → 轮廓特征提取 → 形状分类；在目标区域内使用 HSV 颜色统计进行颜色分类。

可使用轮廓面积、周长、圆度、近似多边形顶点和旋转矩形长宽比。阈值必须根据实物、视角和尺度验证。侧视图可能无法区分俯视轮廓类别，应明确每个视角负责的属性。

参考：https://docs.opencv.org/4.13.0/dd/d49/tutorial_py_contour_features.html

## 路线二：深度学习

以 ResNet18 迁移学习作为分类基线。第一版将每个允许的“形状+颜色”组合视为一个类别，分别推理两个视角，再进行结果融合；这不是已训练模型。

若不同视角分布差异明显，评估分视角训练；若后续需要联合学习，可采用双分支特征融合。确定数据和类别前不承诺识别精度。

参考：https://docs.pytorch.org/tutorials/beginner/transfer_learning_tutorial.html

## 数据组织与评估

每件物料记录物理实例 ID、类别、视角、采集批次、光照和图片路径。按物理实例及采集批次划分训练、验证、测试集；同件连拍和双视角图片放在同一划分中。测试集保留到最终评估。

报告混淆矩阵、各类别准确率、被接受结果的误识别率、拒识率、重拍率与单件耗时。采集正常、遮挡、模糊、反光、空场及多件物料样本。

## 融合与拒识

先检查图像质量，再分别识别。两路一致且分数达标时接受；冲突或质量差时有限重拍。初期不自动降级到单相机。

形状和颜色应分别设置阈值。0.9 仅是暂定评分阈值，不能解释为已达到 90% 正确率。规则评分不等于概率；神经网络输出也需验证校准。

参考：https://scikit-learn.org/1.8/modules/calibration.html

## 报告可用描述

本系统拟采用双相机视觉识别方案，在物料到位并停稳后采集同一物料的两个视角图像。经图像质量检查与预处理后，分别提取形状、颜色信息，并根据视角可靠性和结果一致性进行融合。系统对不满足接受条件的物料执行有限次数重拍，超过上限后进入异常处理。识别成功后锁定类别及对应盒号，通过带唯一 ITEM-ID 的通信任务与控制端交互，完成反馈确认后进入下一件处理。

以上为设计描述，实际方法、参数与性能需实现及实验后补充。
