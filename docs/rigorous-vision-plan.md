# 双视图视觉识别：数据、模型与验收方案

日期：2026-10-17。状态：实施建议，未完成部分不得写成已实现指标。当前代码与权重保留为演示基线。

## 1. 目标与结论边界

输入同一静止场景的一对顶视/侧视图，先定位与对应物体，再输出每个物体的“颜色＋形状”。两个属性均相同才归入同一类。输出包含对应 ID、两图位置、类别、接受/待复核状态及原因。40 mm 是物料范围，不是当前已实现的尺寸测量能力；材质暂不进入标签。

短期先验收已配对的单物体，再扩展全场景多物体。未知形状不强制映射到现有四类；不能承诺两幅投影足以区别所有三维物体。同色同形且遮挡严重时，实例对应可能不唯一；保留无法判定状态。不得用未核实的机械移动或人工干预流程代替比赛要求。

现有 377/377 正确只说明固定样件、固定视频内的流程运行通畅。训练与验证涉及同一实物、视频、背景；中间隔帧不能消除这些相关性。24/24 扰动检查只覆盖由 8 对图片衍生的少量变化。两项均不构成独立测试成功率、现场成功率或未知类别识别能力证据。

## 2. 数据优先级与采集

### 第一优先：真实成对数据

每次拍摄记录 pair_id、physical_object_id、session_id、camera_id、view、color、shape、image_path；多目标另记录 scene_id、目标框、实例 ID 及跨视图对应关系。两相机拍同一静止摆放，尽量同步，不能把不同姿态视频中“类别一样”的图当作真实同步对。

先为现有八类制定固定标签字典。多棱柱如不确认棱数，继续用宽类别 prism；不要从模糊顶视图猜标签。颜色和形状各自标注，物理实物赋予不可重复的 ID。

理想的初始采集预算（是建议规模，不是保证精度所需充分样本数）：

- 每类 5 个不同物理实物，每实物约 20 次不同摆放：8 × 5 × 20 = 800 对、1600 张真实照片。
- 按实物每类 3/1/1 分到训练/验证/测试，约 480/160/160 对；同一实物连拍、其他批次照片、双视图以及所有派生增强必须在同一分区。
- 每分区专门安排拍摄批次、背景和光照，测试集优先使用训练未出现的实物与独立拍摄批次。若批次包含跨分区实物，应重安排采集或按共享实物/批次的连通分组划分；仅把 (object_id, session_id) 拼接成 group 并不能保证同一 object 不跨分区。
- 暂时只有每类一个实物时，仍可新增独立拍摄批次验证，但只能报告“同实物跨批次”，不能称“新实物泛化”。若不能满足分组，明确标记独立测试未完成。
- 拍摄中心/边缘/角落、多方向、工作范围内不同视距、轻微透视、正常/偏暗/偏亮、软硬阴影。角度范围按真实安装和采集设备测得，不以任意扭曲图片代替真实视角。
- 另采空场、多目标、相互接近、部分遮挡、强反光、未知形状、其他颜色。多目标每个可见物体均标注，不只标主目标；双视图不可见的物体标为不可配对，不强配。

### 现有素材与合成素材

保留原始照片作为真实数据基准。绿底图、离线旋转、生成图片均为派生数据，只进入相应原图所属的训练分区，不计为独立拍摄样本。现有自动框需人工复核。测试集必须真实拍摄，不用 AI 生成或抠图换底替代。

几何合成优先从已知 CAD/三维网格渲染，保存准确形状、相机姿态和双视图对应；随机化背景、光源、相机与材质。生成式图像易改变几何边界，作为可选辅助且需审核。所有合成都不能证明实物表现。

## 3. 模型架构与分阶段实现

### 阶段 A：已配对单物体，优先可验证成果

输入用户选定的同一物体 ROI，或在固定场景内可靠定位的单目标。沿用 MobileNetV3-small：两路共享小型主干，保留视角身份，拼接顶视/侧视特征，再做形状分类；颜色独立输出，最终 class_key = color_id + shape_id。共享主干不等于忽略两个视角的位置顺序。

先比较三个基线：顶视单路、侧视单路、双视图。只有在相同独立测试集合上实际改善，才宣称双视图收益。先训练头，再以较小学习率微调最后若干主干层；保留冻结主干结果，防止少量数据下微调反而变差。随机种子固定并至少报告 3 次训练的波动，模型选择只用验证集。

形状预处理比较灰度 ROI 与 RGB ROI；不要默认颜色阈值分割永远正确。避免只凭投影面积、像素长宽或阴影分类。颜色基线在经白平衡、曝光控制的目标区域统计 HSV/Lab，并设置混色/颜色未知；后续若采样证据表明不足，再训练颜色头。两视图颜色一致只是必要检查，不能证明对应实物相同。

### 阶段 B：多目标定位

引入轻量目标检测器，例如固定版本的 YOLO nano 模型，先训练“物体”类定位，再由形状/颜色模块细分。与按最终八类检测的基线在相同数据上比较，避免仅凭架构偏好定结论。未知物体定位能力也要测试，单类检测不天然保证检测所有新形状。

仅当紧邻、遮挡、背景混色使框内颜色严重污染时，再评估实例分割；短期不同时增加复杂检测、分割、融合网络。分别报告检测 Recall、Precision 和 mAP，再报告整个系统的成功率，不能用 mAP 代替分类与配对成功。

### 阶段 C：真实跨视图对应

固定相机后标定内参、畸变与相对位姿，在共同可见范围采集对应数据。候选匹配综合颜色、形状特征、外观和几何约束，使用有未匹配选项的一对一分配；不得仅按图像左右顺序、颜色或最高分强制匹配。俯视/侧视目标框中心通常不是同一个三维点的精确投影，不能把其极线距离当作绝对真值。

对于重复同色同形物体、严重遮挡、某视角不可见、匹配次优解接近最优解的情况，输出无法确定对应；必要时通过经规则确认的受控观察或重拍取得补充信息。训练分类成功不代表实例对应成功。多目标模块未验收前，界面必须标明仅支持手动配对 ROI。

## 4. 训练与工程约束

- 先按实物/批次划分，再增强。建立自动检查：实物 ID、pair_id、原图父 ID 不跨分区；图像哈希与近重复只作额外检查，不能替代语义分组。
- 标签、类别表、相机配置、数据清单、依赖版本、训练参数、随机种子、代码提交号与 checkpoint 摘要一同保存。
- 训练集允许小幅旋转、透视、曝光、模糊、噪声；范围来自真实设备。形状变换不得改变真值；颜色增强不得把红变蓝而仍保留原标签。不依赖只在训练或某类出现的填边/背景。
- 对多个视图的空间增强区别处理：独立大幅透视可能破坏真实跨视图几何关系。匹配训练应使用同步物理扰动、标定投影或重新采集。
- 单独保存最难类别、错误原图和重拍记录，不只展示成功示例。缺文件、标签非法或配对不完整时训练应失败退出，而不是静默跳过。
- 已有 3.9 MB 权重可作为候选基线，但阈值 0.75/0.3 等仍是启发值，不是已证明的稳定性界限。

## 5. 分数、拒识与成功率

神经网络 softmax 分数不直接等于正确概率。条件允许时在单独验证/校准数据上做温度缩放等后处理，再看校准曲线与误差；温度缩放不能解决未知类别、数据分布变化或错误配对。数据过少时不强行拟合校准，继续显示“模型分数（未校准）”。

接受条件同时检查：图像质量可用、目标完整、对应无明显歧义、颜色可信、形状分数/间隔满足验证集选定门槛。选门槛时一起看接受覆盖率与错误率，不能靠大量拒识制造高正确率。未知样本集用于测量“未知被当已知接受”的比例，未见未知集合仍无全覆盖保证。阈值选择与最终测试分开，测试后再调整就需要新的测试集。

界面分成三种信息：

1. 单个物体：top_id、side_id、框、候选“颜色＋形状”、接受/待复核及原因、模型分数。
2. 无真值实时运行：已检测数、已配对数、接受数、复核数、耗时；不能显示为实际成功率。
3. 有真值评估：样本总数、完整正确数、错配/错色/错形/漏检/额外误检/拒识等错误、各类结果和混淆矩阵；保存完整日志。相同样本重复测试或多次重拍，不得当作多件独立成功样本。

## 6. 验收指标及统计口径

单物体任务成功定义：在固定时间/重拍预算内，配对正确，颜色与形状均正确且被系统接受。拒识、超时、图像缺失或任一属性错误都不是该次任务成功。

- 端到端成功率 = 完整成功的真实目标数 / 全部待识别真实目标数。
- 接受结果正确率 = 正确接受数 / 全部接受输出数；额外误检输出计入错误接受。
- 接受覆盖率 = 得到接受结果的真实目标数 / 全部真实目标数，不把重复输出或假目标算覆盖。
- 多目标另报告匹配准确率、漏检、误检和整场景完全正确率；场景完全正确要求无漏检、无多报、无错配、无错类。
- 按八类分别报告、宏平均、光照/视角/位置/遮挡条件分层结果；只报总均值可能掩盖薄弱类。
- 延迟报告预处理＋检测＋配对＋分类的端到端 P50/P95，说明设备、图像尺寸、目标数量、冷启动及是否含采集时间。不能把 GPU 神经网络耗时当作系统总耗时。

示例：100 件真实目标，90 件正确接受、3 件错误接受、7 件拒识，无额外误检；端到端成功率 90%，接受结果正确率 90/93≈96.8%，覆盖率 93%。三个数必须同时看。

建议的早期工程门槛（目标，非已达到结果）：限定已知八类、单目标/人工确认配对场景，独立实拍端到端成功率至少 95%，每类至少 90%；接受结果正确率争取至少 99%，同时公开覆盖率；RTX 3060 本地单对推理 P95 暂以 200 ms 为优化预算，不含采集与机械动作，最终部署硬件另测。多目标阶段重新设验收集，不能沿用单目标指标。

所有比率同时给样本量、物理实物数、批次数及不确定性。以真正独立同分布试验为前提，100 次零失败对应单侧 95% 精确二项成功率下界约 97.05%；若要同样方法得到至少 99% 的下界，零失败时约需 299 次独立试验。连续帧/同一物体重复摆放有相关性，不能直接冒充这些独立试验；按实物/批次聚类评估，不足时明确统计证据不足。即使满足该统计门槛也只适用于所测试分布，不保证未知环境。

## 8. 对现有仓库的具体升级清单

- training：实物/批次分组清单，分区断言，类别配置，冻结/微调对照，三随机种子记录。
- vision：颜色判断增加未知状态；定位改为独立模块；ROI 双视图分类与全场景匹配接口分离；类别顺序随权重保存/加载，不能只依赖硬编码。
- evaluation：带真值的目标对应评估，漏检/误检/错配计数，分层表、覆盖率/风险曲线、聚类不确定性和 P95。
- display：区分模型分数、历史实测成功率、当前复核状态；必须显示样本量和测试范围，禁止用单次模型分数代表成功率。
- release：权重摘要、数据版本、依赖版本、提交号和报告绑定；自动测试空场、未知色、多目标、非居中、同色异形、同形异色、视图错配和缺失视图。
