## 接口核对结果

1. 当前视觉输出为分类候选；实例对应未完成，24对同色异形错配中22对仍输出候选。`automatic_sorting_allowed=false` 必须保留。
2. 顶视定位与抓取坐标尚未标定。绿色托盘用途已有确认；旧文档后文仍写“用途待确认”的部分被顶部新确认取代，不再重复询问。可达范围须实测、不可只按用户确认写成测试通过。
3. 八个训练类别与六个盒不是固定一一对应关系。要按本轮实际类集建立盒映射并校验可容纳性；出现超出盒数的不同类别不能静默合并、覆盖或取模映射。当前没有自动建图或溢出处理的实测成果。
4. 控制 `type` 草案与显示 `event` 实现是两层未联调接口；显示状态接受不等于真实刷新完成。
5. 已修复显示累计数跳号：每个唯一合格事件只能加一，显式count只做连续性校验；未知类、缺资料、非法盒号不计数。仍只有内存去重；不能宣称断电恢复幂等或传感器验证通过。
6. 显示目录的颜色块图片、黄色三角件及盒号仅为界面夹具，不是已训练能力、真实货物照片或现场映射证据。
