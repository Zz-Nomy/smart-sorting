# 任务分工与验收

负责人暂留空，由队伍共同认领。

| 模块 | 第一项任务 | 验收标准 | 负责人 |
|---|---|---|---|
| 需求与机械 | 确认物料清单、到位信号、转盘位置 | 有尺寸图和动作时序图 | 待认领 |
| 视觉采集 | 双相机采集并保存配对图像 | 有 ITEM-ID、视角、时间与拍摄批次 | 待认领 |
| 视觉算法 | 质量检查、形状和颜色识别 | 输出类别、评分、拒识原因 | 待认领 |
| 数据与训练 | 采集标注、划分数据、训练基线 | 独立测试集与评估报告 | 待认领 |
| 上位机通信 | 编解码、超时、同 ID 重发 | 能用模拟设备验证正常和异常路径 | 待认领 |
| ESP32 | 转盘控制、到位反馈、重复任务处理 | 同 ID 重发不重复动作 | 待认领 |
| 显示与集成 | 屏幕显示、全流程日志 | 本件完成前不启动下一件 | 待认领 |

顺序：确认需求 → 离线识别 → 双相机采集 → 模拟串口 → 硬件联调 → 完整验收。
