# Smart Sorting · 智能分拣

双相机视觉识别与 ESP32 分拣控制项目。

当前状态：项目起步框架。物料类别、相机安装位置、运行平台尚未确认，没有训练权重或硬件联调结果。

## 系统流程

物料到位 → 建立 ITEM-ID → 双相机采集 → 图像质量检查 → 形状与颜色识别 → 双相机融合 → 接受或有限重拍 → 类别映射盒号 → 串口下发 → ESP32 执行 → 完成反馈 → 下一件。

## 目录

- `vision/`：采集、预处理、识别与融合（待实现）
- `training/`：数据集及训练方案（待实现）
- `firmware/`：ESP32 控制程序（待实现）
- `configs/`：参数配置示例
- `docs/`：系统设计、接口协议、任务分工
- `tests/`：识别、协议和联调测试（待实现）

## 开始参与

阅读 [协作指南](CONTRIBUTING.md)，从 [任务清单](docs/tasks.md) 选择任务，通过 Issue 认领，再提交 Pull Request。

## 当前需要确认

1. 竞赛或设备要求：形状、颜色、尺寸、材质和分类规则。
2. 相机数量与接口、两个视角、光源及背景。
3. 上位机平台、转盘机构、物料到位与到位确认方式。
4. 单件耗时与可接受误识别率。
5. 数据采集、标注和训练资源。

详细设计见 [视觉模型设计](docs/vision-design.md) 与 [通信协议草案](docs/protocol.md)。

不向仓库提交密码、令牌、个人资料或未经确认可公开的文件。原始数据和模型权重默认不提交。
