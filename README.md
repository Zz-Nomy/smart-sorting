# Smart Sorting · 智能分拣

双相机视觉识别与 ESP32 分拣控制项目。

当前状态：已有可运行的[双视图颜色＋形状识别原型](vision/dualview/README.md)、训练代码、带真值评估和本地权重。当前覆盖红/蓝两色及四种形状；独立实物测试、多目标配对和硬件联调仍未完成。

## 当前运行与证据

先阅读[原型运行说明](vision/dualview/README.md)，再按[证据索引](docs/evidence-index.md)区分软件检查、相关内部数据与未完成验收。仓库不含权重及原图，不能仅克隆后直接演示；本地演示包另含可信权重和八对既有样例，需要兼容 Python 环境。

从仓库根目录执行 `python -m unittest discover -s tests -v` 可运行43项软件测试。此数量不代表独立实物识别实验。

## 拟定系统流程（完整闭环尚未实现）

托盘选择目标 → 建立 ITEM-ID → 同一实物双视图采集与配对 → 质量和类别判断 → 本轮盒号映射 → 单件机构执行 → 完全入盒确认 → 显示完成反馈 → 下一件。当前分类器始终返回 `automatic_sorting_allowed=false`，多目标实例配对及机构闭环尚未验收。显示端状态接受不等于渲染完成。

## 目录

- `vision/dualview/`：双视图轻量识别模型、演示界面、评估及内部检查报告
- `training/`：训练入口、图片对标注示例
- `firmware/`：ESP32 控制程序（待实现）
- `display/`：Raspberry Pi 800×480 分拣结果屏幕端，支持串口 JSON、演示模式和去重计数
- `configs/`：参数配置示例
- `docs/`：系统设计、接口协议、任务分工
- `tests/`：43项数据、视觉、训练封存、评估、人工审计及显示状态测试；硬件联调待完成

## 后续验证缺口

当前用户要求按颜色＋形状分类，物料尺寸在40 mm以内，材质不纳入标签；托盘用途与移动夹爪覆盖范围已有用户确认。仍需真实独立实物/批次数据、实际相机标定、整机尺寸与容量量测、入盒传感器及显示完成反馈、部署硬件时延和完整现场验收。缺少这些证据时不承诺现场成功率，也不以重复抽帧或合成图替代。

当前设计见[严谨实施方案](docs/rigorous-vision-plan.md)、[规则与接口核对](docs/rules-interface-audit.md)和[通信协议草案](docs/protocol.md)。`docs/vision-design.md`保留早期路线讨论，不代表当前实现。
